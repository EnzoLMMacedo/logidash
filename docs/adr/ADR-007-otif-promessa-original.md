# ADR-007 — OTIF medido contra a promessa original

## Status

**Planejado.** Esta nota existe só para o índice e a navegação no vault. Ainda não há decisão registrada aqui.

A definição vigente de `otif` no [[kpis]] já usa `data_prometida_original` como base oficial e rejeita `data_prometida_vigente` para esse indicador. Esta ADR, quando escrita, deve formalizar essa decisão de negócio. Até lá, vale o dicionário; nada além do título, do status e dessa referência deve ser lido como regra nova.
